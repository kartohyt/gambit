# Гамбит

Шахматы и русские шашки в браузере. Один файл `index.html`, без сборки и без своего сервера.

- Игра против бота: три уровня сложности.
- Вдвоём за одной доской.
- Онлайн с другом: создайте игру, отправьте код или ссылку, соперник подключается напрямую из браузера (через [PeerJS](https://peerjs.com/)).
- Отчёт после шахматной партии: точность, зевки, ошибки, лучшие и бриллиантовые ходы; любой ход можно открыть на доске.
- Русский и английский язык.

## Онлайн

Игроки соединяются браузер к браузеру (WebRTC). Чтобы найти друг друга, они используют бесплатный общий сервер PeerJS; сами ходы идут напрямую. Оба игрока должны быть на странице одновременно. В некоторых сетях (строгий NAT, часть мобильных операторов) прямое соединение может не установиться.

## Запуск локально

```bash
python -m http.server 8000
```

и откройте http://localhost:8000.
