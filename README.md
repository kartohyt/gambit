# Гамбит

Шахматы и русские шашки в браузере. Один файл `index.html`, без сборки и без своего сервера.

- Игра против бота: три уровня сложности.
- Вдвоём за одной доской.
- Онлайн с другом: создайте игру, отправьте код или ссылку, и соперник подключится из своего браузера.
- Отчёт после шахматной партии: точность, зевки, ошибки, лучшие и бриллиантовые ходы; любой ход можно открыть на доске.
- Русский и английский язык.

## Онлайн

Ходы передаются через бесплатные публичные MQTT-серверы ([EMQX](https://www.emqx.com/en/mqtt/public-mqtt5-broker) и [HiveMQ](https://www.hivemq.com/mqtt/public-mqtt-broker/)) по обычному WebSocket, поэтому игра работает через любые роутеры. Страница подключается к обоим серверам сразу и пользуется тем, что отвечает. В каждом сообщении передаётся вся партия, так что потерянный ход восстанавливается следующим сообщением, а друг, обновивший страницу, возвращается в ту же партию.

Серверы публичные: ходы видны любому, кто знает код игры. Оба игрока должны держать страницу открытой.

## Запуск локально

```bash
python -m http.server 8000
```

и откройте http://localhost:8000.
