# Гамбит

Шахматы и русские шашки в браузере. Один файл `index.html`, без сборки и без своего сервера.

- Игра против бота: три уровня сложности.
- Вдвоём за одной доской.
- Онлайн с другом: создайте игру, отправьте код или ссылку, и соперник подключится из своего браузера.
- Отчёт после шахматной партии: точность, зевки, ошибки, лучшие и бриллиантовые ходы; любой ход можно открыть на доске.
- Русский и английский язык.

## Аккаунты и онлайн

Аккаунты и онлайн-партии живут в [Firebase](https://firebase.google.com/) (бесплатный тариф): вход по почте и паролю, база Cloud Firestore. Играть онлайн можно только после входа; с ботом и вдвоём за одной доской можно и без аккаунта.

Каждая онлайн-партия — один документ в базе со всеми ходами, оба игрока слушают его в реальном времени, поэтому обновление страницы ничего не ломает.

Права проверяют правила Firestore на сервере, а не страница: ник уникален, админом считается владелец ника ItzKartoh с подтверждённой почтой, забаненный игрок не может создать игру, войти в чужую или сходить.

## Запуск локально

```bash
python -m http.server 8000
```

и откройте http://localhost:8000.
